## 数据保存

数据库名 `free-university-v1`，`archive` 表保存版本化状态快照。实体分别存在独立数组中，使用 ID 关联，校园对象不持有课程数据。串行写入避免较早的存档覆盖较新的修改。

数据库名称、表结构和主记录 `main` 不变；存档数据版本从 `version:1` 升到 `version:2`，`contentVersion:3` 标记本次内容安装。首次升级在同一事务内保存 `backup-before-v03` 并写入升级存档；设置页可导出升级前副本。迁移只给仍存在且保留原始标记的七门初始课程添加内容，不重建用户已删除的课程。用户修改过的旧字段、任务、资源、日志与布局保留。升级验证失败时阻止写入，并提供原始存档导出。

第一次打开才初始化课程和校园；以后加载存档，新增/删除的课程不会被自动恢复。`Course.seed` 标识初始模板。课程删除会移除对应大纲、任务和计划，学习记录和展品保留并标为已归档课程。拆除建筑与删除课表安排都不会删除学习活动记录。

界面右上角显示实际保存状态，存储失败会提示导出备份。数据只保存在当前浏览器及当前网址中：localhost 与线上站点、不同浏览器或设备之间不会自动同步。迁移时使用设置中的 JSON 导出与导入。清除站点数据可能导致存档丢失。

## 验收路径

V0.3 推荐路径：教务处 → 经济学入门 → 第一单元「为什么时间也是一种成本？」→ 打开 CORE Econ → 勾选步骤、填写练习/笔记 → 保存学习记录 → 成果馆。

备课室位于教务处顶部。课表默认显示已准备好的课时；勾选「查看原有 / 自由学习任务」仍可安排旧任务。资源卡可打开图书馆反向关联，图书馆也可返回对应课时。

1. 校园教学楼 → 高级日语表达 → 任一任务 → 写笔记 → 记录本次学习 → 成果馆查看记录。
2. 课表 → 经济学任务“安排” → 周三 → “移动”至周五 → 刷新检查。
3. 课程 → 开设新课程 → 添加章节 → 添加知识节点 → 添加任务 → 课表任务池查找。
4. 建造模式 → 圆冠树 → 点击空地 → 完成布置 → 刷新检查。
5. 完成活动但不勾选掌握 → 课程进度与节点状态分别变化；再次练习并勾选掌握 → 成果馆出现唯一知识晶体。

## PDF 导入补充 · 2026-10-25

材料备课室选择 PDF 后，文档在浏览器本地解析，原始文件不上传。支持20MB以内文字型PDF，每次最多选择40页；默认先选前5页。预览可编辑，确认后回填材料原文；每份最多24000字符，超过上限需缩小页码或自行删减，不自动截断。空白或扫描页会提示，无文字时明确提示需要OCR；加密PDF提示先在本地阅读器中解锁。

存档保留提取/修正后的文字、文件名及PDF物理页码，不保存原始PDF二进制。AI调用仍需用户主动点击。双栏、表格、特殊编码字体的阅读顺序可能需要人工修正。

## API Key 本地保存更新

AI连接填写后保存在本站当前浏览器localStorage，刷新和重新打开自动读取；配置框显示已保存，留空保留原配置，可更换或清除。Key不进入课程JSON、PDF索引备份或源码；不同域名/浏览器独立，清理本站数据后需重新配置。此前版本“仅内存保存”的说明为历史行为。

API Key 保存与请求前均进行字符校验；可处理外层粘贴引号、空白与Bearer前缀。内部异常字符不会被静默改写，需在AI连接中重新复制；无效新输入不覆盖已有配置，旧无效配置可更换或清除。

AI JSON 回复兼容更新：支持代码块、外围说明文字和文本分部；明确区分空正文、错误类型、截断与格式损坏。格式损坏时最多追加一次语法修复，可能产生额外API费用；不重传整本PDF或重跑已完成章节。修复后仍校验内容字符串/字面量及业务结构，不接受改变原内容的修复。

### 书架分析可靠性更新
书籍总览与章节分析现在先保存连贯正文，再整理小型大纲。大纲处理失败时，正文仍能查看，点击继续只处理未完成阶段。最近失败的诊断可在书籍页展开或导出（含模型回复与可能的教材摘录，仅存本机，不自动发送给开发者）。旧存档无须重置。

### 阅读与概念探索
书籍章节提供概念高亮、阅读宽度和大字行距设置。概念卡展开后可按需生成情境解释、选择题反馈，再检索现实新闻/政策/案例。首次准备需要已保存的 AI 连接，后续读取本书缓存；备份仍使用书籍页的「导出目录与分析进度」。本轮没有改造材料工作台旧概念弹窗。

### 一次准备整章
「准备本章学习内容」会自动接着准备概念练习和本章共享现实资料。已分析的旧章点击「继续备齐本章学习内容」即可补齐，保留原正文及已有概念卡。阅读展开卡片不调用AI；额外探索才重新请求。失败可继续，搜索来源先单独保存。paragraph引用缩为可点开的〔源〕，未核实的编号不作为原书精确页码。

### PDF 原书课程
打开书架里的PDF，点「把这本资料加入课程」，即可按真实大章建立课程。课时直接读取原书备课缓存，支持原有课表、笔记和完成记录；后续可同步新备内容。备份时请同时保留课程JSON、书籍目录/分析索引和原PDF，三者当前分别存储。

### 图书馆统一入口
底部「图书馆」默认是「我的 PDF」，上传的整本资料、章节备课及加入课程均从这里进入。「收藏资源」保存网址、教材、指南；文字材料备课室通过顶部链接进入。原PDF、收藏和课程存储保持原样，旧链接继续可用。

### 课程系统：对话开课、分类与删除
课程页「和 AI 一起开课」可逐步讨论主题与偏好，搜索资料，预览三节入门路线，确认后开课并可选排入本周。聊天与草案本机保存；摘要来源不等于读过完整教材。课程可按学科分类、自定义分类；删除时可保留足迹成果或删除课程独有资料，共享资料受保护。章节课时完成会收藏唯一章节纪念；复习可继续保存记录，不自动代表知识掌握。本轮没有新增校园美术与可放置素材。

### 全站AI与课程菜单
顶部「AI设置」是全站共用配置入口，保存一次供所有已实现的AI功能读取。课程卡片右键或点右上角⋯打开编辑/删除，支持键盘；学科分类使用下拉选择及单独自定义字段，课程筛选显示实际结果数量。

### 开课阶段与新版讲解
对话满足基本方向后停止追加问题，先生成三课大纲，再按确认的路线逐节准备。已完成课时会保存，继续只补未完成部分。新课程讲解使用独立教学流程，具体网页读取不足时会提示补充URL，不把目录简介标成已备课。旧草案可「按新版方式另备一版」，原课程和笔记保留。主按钮与说明分行放置。

### 重新生成与版本
开课页顶部「重新生成」支持重做大纲或保留大纲重新备课，并可补充调整要求。旧草案先存入「备课版本」，可随时切回；原课程、笔记与记录保留，新版本确认后另行开课。版本随主课程JSON备份导出，仍只保存在当前浏览器。

### 基础需求确认
新大纲在学习重点、基础、讲解方式及每节时长明确后，由用户核对并确认再生成。AI补出的目标或对话轮数不算用户确认；不确定基础时可主动选择从零开始。「开启新的对话草案」位于页面顶部，旧草案自动保存到版本中。

### 对话面板与资料搜索
备课对话在固定面板内滚动，桌面与需求框对齐，输入区不随聊天增长而下移。课程资料使用DeepSeek全网多组短查询，优先中文、补充英文，可选不限语言；来源扩展到大学公开课、开放教材、研究机构和具体讲解。可查看检索词与各网页读取结果，也可扩大范围重新查找，保留已备课时。


### 课程资料访问策略（2026-10-27）

开课先独立保存大纲；课时以公开可读的知识文章、讲义和开放教材章节为主。网页不可读、仅目录简介或需登录/付费时，保留为可自行购买/借阅/导入的延伸推荐，并按课时主题补搜公开正文。仍缺正文时允许生成标明依据的AI基础导学，不冒称已经阅读推荐书，不伪造引用、新闻、现行政策或数据。账户密钥/余额错误仍须修正后继续。

每节短课新增可选 preparation（mode、sourceUrls、notice），随课程、草案与JSON存档保存；兼容旧存档，无需清空数据库。预览、课堂与任务池展示依据类型，图书馆资源说明推荐是否为必读。


### 阅读课堂与持续续学（2026-10-27）

AI短课课堂使用安全Markdown阅读排版、小标题、加粗与语义重点提示。支持大字、专注模式；正文选字后可黄色/绿色高亮、紫色划线、添加与编辑评论，标注锚定可读文字而非Markdown符号。正文改写后尝试重新定位，无法可靠匹配的标注保留在边栏。旧随手笔记仍可展开查看。

看问题、读解释、做情境三个环节分别记录；可以主动跳过。三个环节都标记后自动完成课时、更新活动并创建一次Done List记录，重复回看不会再次记完成；掌握知识独立标记。课时与课程进度计入环节进度。

AI生成课程的大纲页，以及最后一课完成区提供“生成下一单元”：读取已有单元标题、学习问题及完成状态，准备新大纲与三节课；确认后追加到同一课程。新资料、课时、知识节点和路线追加保存，不覆盖旧课时、笔记、标注和进度。未确认草案归档以便恢复。

资源卡默认三行摘要，完整说明、指南与反向关联折叠；通用资源卡不再放语言工作室操作，语言探索仍从语言课程进入。

数据扩展：Lesson可选annotations与readingState，PlanningDraft可选continuation；兼容旧存档，无需清空或重置数据库。JSON备份包含标注、评论、环节状态和续学草案。


标注删除补充：右侧列表直接删除，选区工具条可删除与选区重叠的完整标注；提供当前课堂内最近一次删除的撤销，恢复原标注ID与评论，不覆盖后来添加或编辑的内容。后续教案使用自然假设情境，来源身份集中在资料区，既有教案不自动重写。


### PDF整本与局部重做、生成进度（2026-10-27）

PDF课程页顶部可进入“整本 / 局部重新生成课程”，每个PDF章节也有“重新生成本章”入口。原书页提供整本补齐、整本重做、选定章节重做，以及最多1000字调整要求。按真实目录页码逐章提取与分部生成，不把整本一次塞入模型。支持暂停/刷新后继续，成功章节跳过；失败与附加资料缺失分开显示。新版没有完整正文前不覆盖旧版；章节最近3个旧版可预览恢复。原PDF、课程ID、课时ID、学习进度与笔记保留，结果同步至关联课程。没有原PDF但章节全部文字已缓存时可用缓存继续，否则需补回原文件。运行期间保持原书页打开。

PdfBook新增可选generation、chapterRevisions、chapterHistory，仍存于原books表；无需清空数据库。导出原书目录与分析进度包含任务、断点及版本，原PDF仍独立保存。页码未确认的目录项明确显示为未生成。总览保留原来独立操作。

全站AI/搜索请求统一显示等待条、已用时间及估计等待范围。估计依据近期成功请求耗时，只存动作名称与数值，不存密钥、提示词或教材内容。单次请求使用不定进度，不伪造模型百分比；整本任务展示真实已处理章节数、备齐/待补/失败数量及粗略剩余时间。
# PDF 完整课程与统一阅读（2026-10-27）

单章试读入口已升级为「完整课程大纲 / 备课」。先按整本真实目录逐章整理大纲，沿用已有课时；确认完整大纲后按原书片段逐课准备。大章分批整理大纲，覆盖全部原文片段，不再限制整章只能八课。支持中断续备、跳过已完成内容、章节失败隔离与单章调整。大纲采用后即能看到所有课时安排，内容未备好的课时明确显示待备课；已备好后填入原课时ID。已有单章试读内容会沿用。

课程教学大纲以课堂为主，原书分析移到「原书与参考资料」。原章节分析、概念卡、PDF、旧笔记和学习记录均保留；原书分析不再计入课堂推荐或新排课。局部采用新版大纲时，旧课堂移入参考区，保留旧ID、进度和标注。备课视图与原书阅读视图分开，避免显示两套课程入口。

学习路线默认折叠，展开后的目录在内部滚动。材料正文、章节分析、概念解释和资源指南共用可选择的阅读渲染与高亮、划线、评论、删除和撤销。原PDF提供「文字阅读与划线标注」模式；扫描页需先识别出文字，画布版面本身不支持文字选择。相同正文的跨入口标注共用同一文档记录；同一课的课堂与资料库讲解直接共用课时标注。原有笔记改为历史折叠查看。

数据新增可选 Data.readingDocuments、PdfBook.teachingCourse、分部大纲断点和课时大纲关联，兼容已有存档，无需重置数据库。校园JSON包含阅读标注；PDF文件及课程生成断点仍通过原书索引单独备份。运行生成时请保持备课页打开，离开后可以继续。
# 大纲原文关联修正与站内后台备课

原文预先由程序分组，AI只返回每组的课时标题、问题和教学重点，原始片段ID由程序绑定。旧版已通过验证的大纲继续沿用；缺组或无效教学设计只针对未完成组追加一次请求，成功组有独立断点。不用猜测原书依据，也不以放宽来源检查掩盖错误。

PDF完整课程生成改为全站任务，不依赖备课页是否挂载。在网站仍打开的情况下，可以切换站内页面或标签页；全站浮动入口显示进度、当前请求耗时范围、返回与暂停。相同原文任务防重复启动；支持Web Locks的浏览器防止多个标签页同时为同一本书启动任务。刷新、关闭浏览器或浏览器休眠可能中断，回来继续已保存进度，不宣称关闭后仍在云端运行。API密钥继续只存浏览器，没有新增服务端密钥存储。

后台检查点只更新课程生成字段和新增页面，保留最新阅读位置与章节分析；原课程删除时停止任务，原PDF在任务运行时不能删除。任务状态、分组结果与已完成课时保留在原有本机数据库及原书索引备份中。
# PDF课时校验与保留式补修

PDF教学课时采用独立的正文容量与练习校验规则，普通材料分析仍保持原规则。完整讲解不再受旧1800字符短卡限制；2选项辨析题可用，正确答案范围与逐项反馈仍严格校验。原文输入范围由程序绑定，不要求模型再填写段落编号；范围表示本课实际输入，不冒称精确引文定位。

结构化响应未通过时，收到的课时对象和逐字段问题保存在原书的lessonDrafts中，可在大纲的相应课时展开查看。每次处理最多补修一次失败字段；原有有效正文不会因补修题目而被重写。继续时优先补修已保留的响应，成功课时不重复请求。来源不足的明确拒绝保留原因，不伪造可用内容。

未完成提示按章节列出具体课时和字段，进度浮层限制横向溢出。285项以上自动检查覆盖存档重载、长正文、原文范围绑定、非法答案仍拒绝、定向补修、阻止改写有效字段、70/93断点只请求剩余23课；没有用用户PDF或付费密钥重现真实输出。
